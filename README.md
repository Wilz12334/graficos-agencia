# Gráficos — Landing para GitHub Pages

Landing page responsive para servicios de diseño gráfico, marketing y estrategia.

## Publicar en GitHub Pages

1. Sube `index.html`, `styles.css` y `script.js` a la raíz de un repositorio.
2. En GitHub entra a **Settings → Pages**.
3. Selecciona **Deploy from a branch**, rama `main` y carpeta `/ (root)`.
4. Guarda y espera la URL que entrega GitHub Pages.
